This is a follow-on from my article about building a slip-box system. At this point I've been working in the slip-box for about five weeks now. I have to say it's not all roses and rainbows, there's been a bit of a struggle in that I need to adjust my brain continually to understand that i'm not just streaming consciousness onto cards and that I need to impart structure onto the output so that it's usable.

It's easy to fall into the trap of extracting loads of information from papers and books into the index to the point where it looks nice because it physically feels like you have a lot of content in the index.

But that can be a bit deceiving on the whole.

You end up with a lot of not necessarily useful items, or in one case, a lot of overlapping concepts and things that are harder to unpick.

Part of this is using the index cards as a prompt to remind you of what you read, and reaching back to the source for more context if you need it. The other is pulling out the most important bits that correlate to the system you're trying to describe in the cluster or clusters of the index.
