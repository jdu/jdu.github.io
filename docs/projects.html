Ontarch - Adaptive Architecture Tool

Ontarch is essentially an ontology-based architecture tool, with some SHACL-based validation and reasoning. You can generate a nice self-contained HTML report of your architecture with an explorable graph interface.

It also supports change management and design, you can write up a change proposal file and then view it diffed into your main ontology.

Foli - TUI-based Index Card System

Foli is a terminal-based index card system, with a focus on simplicity and speed. It supports tagging, searching, and linking between cards. It's slowly being updated to allow me to translate index cards into articles, and writing in general.
